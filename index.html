Rock'n'Merge

Fusionnez les jetons, brisez les pierres, atteignez 1024.
Merge tiles, smash stones, reach 1024.

Le jeu

Faites glisser les jetons : deux jetons identiques fusionnent. Tous les 8 coups, une pierre bloque la grille ; une fusion juste à côté la brise. Un défi du jour, la même partie pour tous les joueurs.
